# Amader Pujo Diary ❤️\n\nMobile-first React + Vite website for Buggu, made by Guddu.\n\n## Run\n- Install Node.js 20.19+ or 22.12+\n- `npm install`\n- `npm run dev`\n- `npm run build` for production verification\n\n## Image\nYour uploaded photo is used at `public/images/common/placeholder.jpg`. All scenes share this image. Each pandal currently has six photo selectors, all using the same placeholder. Replace the shared image later or configure unique photos in `src/data/journey.js`.\n\n## Edit pandals\nEdit `src/data/journey.js`. Days 6–9 have five pandals each. Each pandal has six photo positions.\n\n## Progress\nReact state only; no localStorage and no backend. Refresh restarts the journey. The route is a storytelling illustration, not live transport tracking.
